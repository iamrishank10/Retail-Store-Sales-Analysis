# Retail Store Sales Analysis using MySQL

## Project Overview

This project analyzes retail store sales data using MySQL to understand revenue performance, product sales, customer purchasing behavior, and monthly sales trends. The goal is to answer business questions using SQL queries and generate insights that can help a retail store make better decisions.

## Business Scenario

You are working as a Business Analyst for a retail store. The store manager wants to understand which products sell the most, how much revenue the store generates, which customers spend the most, and which product categories perform best.

To achieve this, a database is created in MySQL, sample data is inserted into the tables, and SQL queries are written to analyze the data and answer important business questions.

## Project Objectives

- Calculate the total revenue generated by the store.
- Find the total number of orders received.
- Identify the products available in the store.
- Find products priced above ₹5,000.
- Analyze revenue generated by each product.
- Identify the highest-revenue product category.
- Analyze the number of orders placed by each customer.
- Identify the city generating the highest revenue.
- Calculate the total quantity of products sold.
- Analyze monthly revenue trends.

## Database Structure

The project uses three tables:

**1. Customers**
- `customer_id` — Unique ID for each customer
- `customer_name` — Name of the customer
- `city` — Customer's city
- `signup_date` — Customer registration date

**2. Products**
- `product_id` — Unique ID for each product
- `product_name` — Name of the product
- `category` — Product category
- `price` — Product price

**3. Orders**
- `order_id` — Unique ID for each order
- `customer_id` — Customer who placed the order
- `product_id` — Product purchased
- `order_date` — Date of the order
- `quantity` — Number of units purchased
- `total_amount` — Total amount for the order

## SQL Concepts Used

- Database and table creation
- Primary keys and foreign keys
- Data insertion using `INSERT INTO`
- Data retrieval using `SELECT`
- Filtering using `WHERE`
- Aggregate functions such as `SUM()` and `COUNT()`
- Grouping data using `GROUP BY`
- Sorting results using `ORDER BY`
- Joining tables using `JOIN`
- Limiting results using `LIMIT`
- Date-based analysis using `YEAR()` and `MONTH()`

## Key Business Insights

Based on the sample dataset used in this project:

- **Total Revenue:** ₹244,500
- **Total Orders:** 12
- **Total Units Sold:** 23
- **Top Revenue Category:** Electronics, generating ₹200,000
- **Top Revenue Products:** Laptop and Mobile Phone, generating ₹100,000 each
- **Highest-Revenue City:** Delhi, generating ₹134,500
- **Highest-Revenue Month:** January 2025, generating ₹90,000

These findings are based on the sample data created for this project and demonstrate how SQL can be used to analyze sales performance.
